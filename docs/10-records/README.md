# Records

Spikes, comparisons, and working notes. A record is dated context. It is not a source of truth.

File name: `YYYY-MM-DD-short-title.md`. No ID.

When a conclusion should outlive the note, write it into a requirement, decision, design, or living page, and link this file from that document's Trace section. At the top of the record, add one line: `Promoted to ADR-0001` (or whichever ID received it).
