# Security

Mechanisms: authentication, authorization, sessions, tokens, keys, clients, consent, and trust boundaries.

Describe the mechanism in a `DES` file here. A flow that is mostly security, such as sign-in or token refresh, still lives in [flows](../flows/README.md) and links here. The caller-visible token, scope, or error shape is a [contract](../../06-contracts/README.md). A threat that changes a choice is also a [decision](../../03-decisions/README.md).

Index every file in the [design index](../README.md).
