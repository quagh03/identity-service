# Decisions

Choices that would be expensive to reverse, and the reason. The workings of a choice belong in [design](../05-design/README.md). The caller-visible result belongs in a [contract](../06-contracts/README.md).

Copy [the decision template](../00-handbook/templates/decision.md). File name: `ADR-0001-short-title.md`.

Record ordinary alternatives in the decision's Alternatives section. Write a separate `rejected` ADR when a proposal was reviewed on its own and declined.

When a later decision replaces an accepted one, add the new file, set the old file to `superseded`, and point `superseded_by` at the new ID. Keep the old file.

When you add a file, add a row here and a row in [traceability](../09-quality/traceability.md).
